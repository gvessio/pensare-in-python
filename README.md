# Pensare in Python

**Un laboratorio per scoprire l'informatica**

Questo repository raccoglie materiali didattici interattivi in italiano per le attività di orientamento del **Dipartimento di Informatica dell'Università degli Studi di Bari Aldo Moro**.

L'obiettivo è avvicinare studentesse e studenti delle scuole superiori all'informatica attraverso la programmazione in Python, sviluppando il pensiero computazionale e la capacità di risolvere problemi.

## Materiali didattici

Il percorso è organizzato in **Jupyter Notebook**, che combinano spiegazioni teoriche, esempi eseguibili ed esercizi pratici.

I notebook possono essere utilizzati durante le attività laboratoriali oppure autonomamente, senza installare software, attraverso [Google Colab](https://colab.research.google.com/).
